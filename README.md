# tcga-db

A local DuckDB database of the TCGA PanCancer Atlas (about 10,000 tumours, 33
cancer types) with GTEx normal tissues, built from open-access
[UCSC Xena](https://xenabrowser.net) files:

| Table | Content | Source |
|---|---|---|
| `patients`, `samples` | cancer type, tumour/normal, tissue | Toil phenotype |
| `expression_tpm_wide`, `expression_counts_wide` | ~20,000 genes, TCGA and GTEx on one pipeline | UCSC Toil RNA-seq recompute |
| `somatic_mutations` | 2.3 million calls with protein change | MC3 public MAF |
| `copy_number_wide` | gene-level log2 copy ratio | Broad SNP6, PanCan Atlas |
| `sample_qc` | ploidy, genome doublings, purity, MSI | ABSOLUTE mastercalls |
| `survival` | OS, DSS, DFI, PFI | TCGA Clinical Data Resource |
| `mutational_signatures` | SBS signature exposures | PCAWG SigProfiler |
| `genes`, `tissue_mapping` | GENCODE v23 annotation; TCGA to GTEx tissues | GENCODE, curated |

Used for the TCGA figures in the *Cancer and the Cell Cycle* lectures
(University of Sussex). For those figures without building the database, see
[ccc-tcga-figures](https://github.com/Helfrid/ccc-tcga-figures): marimo
notebooks with a small extract.

## Build the database

Needs [uv](https://docs.astral.sh/uv/) and about 20 GB of disk (3 GB of
downloads, 16 GB once loaded).

```bash
git clone https://github.com/Helfrid/tcga-db.git
cd tcga-db
uv sync
uv run tcga-db init              # create the schema
uv run tcga-db download --load-data   # fetch every source and load it
uv run tcga-db status            # table sizes
```

The database is written to `data/tcga.duckdb`.

## Query it

```python
import duckdb

con = duckdb.connect("data/tcga.duckdb", read_only=True)
con.sql("""
    select p.cancer_type, count(distinct m.patient_id) as tp53_mutant
    from somatic_mutations m join patients p using (patient_id)
    where m.gene_symbol = 'TP53'
      and m.variant_classification <> 'Silent'
    group by 1 order by 2 desc
""").show()
```

Expression and copy number are wide tables (one column per Ensembl gene ID);
look up IDs in `genes`. An interactive tumour-vs-normal expression and
survival explorer:

```bash
uv run marimo run notebooks/tcga_explorer.py
```
